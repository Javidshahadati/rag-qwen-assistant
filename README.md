# rag-qwen-assistant
# RAG Qwen Assistant

## 📌 توضیح
یک سیستم RAG (Retrieval-Augmented Generation) که با استفاده از Embedding و FAISS، از یک سند مشخص پاسخ می‌دهد.

## 🎯 نتیجه
- دقت روی سوالات در متن: ۱۰۰٪
- دقت روی سوالات خارج از متن: ۱۰۰٪
- تعداد توهم (Hallucination): ۰

## 🛠️ تکنولوژی
- Sentence Transformers (Embedding چندزبانه)
- FAISS (پایگاه برداری)
- Qwen2.5-1.5B-Instruct (مدل زبانی)
- Google Colab / Kaggle (GPU T4)

## 🧠 نحوه‌ی کار
۱. سند به قطعه‌های کوچک تقسیم می‌شود.
۲. هر قطعه با Sentence Transformer به بردار تبدیل می‌شود.
۳. بردارها در FAISS ذخیره می‌شوند.
۴. سوال کاربر هم به بردار تبدیل می‌شود.
۵. نزدیک‌ترین قطعه‌ها با FAISS پیدا می‌شوند.
۶. قطعه‌ها + سوال به مدل زبانی داده می‌شود.
۷. مدل فقط بر اساس متن جواب می‌دهد (بدون توهم).

## 📊 ارزیابی
| سوال | نتیجه |
|-------|--------|
| Transformer چیست؟ | ✅ درست |
| تفاوت BERT و GPT | ✅ درست |
| Overfitting یعنی چه؟ | ✅ درست |
| RAG چه کار می‌کند؟ | ✅ درست |
| CNN برای چه کاری | ✅ درست |
| پایتخت فرانسه | ✅ «در متن نیست» |
| آب و هوا | ✅ «در متن نیست» |
| بهترین فیلم | ✅ «در متن نیست» |

## 📝 درس‌های گرفته‌شده
- Embedding چندزبانه برای فارسی ضروری است.
- مدل دستورپذیر (Instruct) بهتر از مدل تکمیل متن است.
- ارزیابی با سوالات خارج از متن، توهم را نشان می‌دهد.
- مدل کوچک (۱.۵B) گاهی در ترجمه‌ی اصطلاحات تخصصی ضعیف است.
