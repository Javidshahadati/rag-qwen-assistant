# RAG Qwen Assistant

## 📌 توضیح
سیستم RAG با Embedding و FAISS که از یک سند مشخص پاسخ می‌دهد.

## 🎯 نتیجه
- دقت روی سوالات در متن: ۵/۵ = ۱۰۰٪
- دقت روی سوالات خارج از متن: ۳/۳ = ۱۰۰٪
- تعداد توهم: ۰
